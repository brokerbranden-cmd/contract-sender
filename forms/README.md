# forms/

Put your licensed Florida Realtors/Florida Bar "AS IS" Residential Contract
(FloridaRealtors/FloridaBar-ASIS-7x, Rev 2/26) here as **`farbar-asis.pdf`**.

PDFs in this folder are gitignored and are never committed. The app overlays
offer data at the coordinates in `src/lib/farbar/asis-field-map.json`.
